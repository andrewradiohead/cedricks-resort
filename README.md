# Cedrick's Resort

Tourism website for the Applied Business Tools and Technologies in Tourism final exam. Fictional business.

## Publish with GitHub Pages

1. Create a new public repository on GitHub named `cedricks-resort` (no README).
2. In a terminal, inside this folder:

```bash
git init
git add .
git commit -m "Add Cedrick's Resort website"
git branch -M main
git remote add origin https://github.com/andrewradiohead/cedricks-resort.git
git push -u origin main
```

3. On GitHub: Settings > Pages > Source: "Deploy from a branch" > Branch `main`, folder `/ (root)` > Save.
4. After about a minute the site is live at `https://andrewradiohead.github.io/cedricks-resort/`.
5. Paste that URL into any QR generator (for example qr-code-generator.com or Canva) and upload the QR image to Google Classroom.

## Add your photos

Create an `images` folder and add `gallery-1.jpg` to `gallery-8.jpg`, plus `room-garden.jpg`, `room-seaview.jpg` and `room-family.jpg`. Until then, colored tiles show. Use your own photos or credit licensed ones in the Gallery credit line.
